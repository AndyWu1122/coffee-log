# 之後要開發的功能（還沒開始做）

## 沖煮方式：手沖／賽風
- 新增紀錄時可以選擇沖煮方式：手沖或賽風
- 細節（欄位、預設值、舊紀錄怎麼算、統計／分享卡片／社群要不要顯示）開發前再討論

## 沖煮手法
- 記錄這一杯怎麼沖（例如：悶蒸、分段注水、攪拌等）
- 形式（自由文字、預設選項、分段紀錄）開發前再討論

## 豆子心得
- 喝完一包後寫一段總評，例如會不會回購
- 之後買豆時可以回頭參考

## 好友的豆子推薦
- 在好友貼文上按「想喝」，存進自己的「想買清單」
- 要考慮：清單存本機還是雲端、好友刪除貼文或改回只有我時清單怎麼辦

## 每週／每月回顧
- 自動整理一段期間的沖煮：沖了幾杯、最愛的豆子、評分最高的一杯
- 可以做成分享卡片（沿用現有的分享卡片）

## 買豆紀錄與花費
- 記錄在哪買、多少錢（可以放在豆子資料上）
- 每月統計咖啡花了多少；也可以算出每杯成本（價格 ÷ 整包重量 × 粉量）

## 外面喝的咖啡
- 咖啡廳喝的也記：店名、品項、評分、照片、筆記
- 要考慮：和自己沖的紀錄放一起還是分開、統計／熱度圖要不要算進去、要不要分享給好友

## 產地地圖
- 精細度：**到主要產區**（已決定）。不做到莊園／處理站（資料太零散、無法內建）
- 畫面：世界地圖上喝過的國家塗色（越多越深）→ 點國家放大，產區用圓點標位置 → 點圓點看喝過的豆子
  - 同一國的產區常常很近（例如耶加雪菲和西達摩），世界地圖上會疊在一起，所以一定要「點國家 → 放大」
- 內建「主要產區清單」：國家＋產區的中英名稱＋大概座標（例如衣索比亞：西達摩、耶加雪菲、古吉、哈拉、利姆、吉瑪…；肯亞：Nyeri、Kirinyaga；哥倫比亞：Huila、Nariño；巴拿馬：Boquete）；圓點只要座標，不用產區邊界
- 產地的輸入（兩個一起做）：
  - 新豆子：豆子表單改成 國家選單＋產區選單（可不選）＋自由文字（莊園、批次）
  - 舊豆子：從現有的產地文字用關鍵字自動比對（中英、常見簡寫如「耶加」「Yirga」）；比對不到產區就只算到國家，國家也比對不到算「未知」，並提示補選
- 地圖上方切換兩種模式：**我的足跡｜認識產區**
  - 我的足跡：只標喝過的國家、產區（越多越深）；點進去看喝過的豆子、最常選的風味（風味輪標籤統計）、平均評分
  - 認識產區（介紹模式）：內建清單的所有產區都標出來，喝過的另外做記號；點進去是產區介紹：
    - 位置、大概海拔、常見處理法，以及**依處理法分開寫**的常見風味（例如耶加雪菲 水洗：花香、檸檬；日曬：藍莓），風味用風味輪的顏色標籤
    - 有喝過 → 下面接「你喝到的」（你選過的風味、評分、豆子），可以對照一般介紹練味覺
    - 沒喝過 → 顯示「還沒喝過」，之後可加「想買清單」（和「好友的豆子推薦」共用）
    - 產區圖鑑：「已探索 8／40 個產區」
  - 介紹是內建的靜態內容（離線可看，更新要靠改版）；先寫最常見的約 15 個產區，之後再補到 30–50 個；內容要查證、用「常見」的語氣，不寫得太絕對
- 要考慮：地圖自己畫 SVG（不用外部函式庫、離線可用），世界地圖的國界資料要簡化、注意檔案大小；豆子資料加欄位 → DB 升級、備份 schemaVersion；社群上傳的產地要不要跟著改

## 評分系統升級（參考 SCA 杯測表）
- 目的：把現在的評分做得更好；現在是總評分 1–5，加上風味 酸／甜／苦／醇厚 各 1–5
- 參考 SCA 杯測表的項目：乾香、濕香、風味、餘韻、酸質、醇厚度、平衡、甜感、乾淨度、整體
- 方向（開發前再討論）：
  - 簡單模式（現在這樣、單手快速打分）＋進階模式（杯測表，平常收起來）
  - 分數要更細（例如半顆星，或杯測的 6–10 分、0.25 一級）
- 要考慮：舊紀錄怎麼轉換或並存；統計、熱度圖的平均評分、分享卡片的雷達圖、社群（雲端 shared_brews 欄位與 check）都會受影響；備份 schemaVersion 要升
